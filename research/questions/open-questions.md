# Open Questions

## Candidate central question

Can a lightweight recurrent policy infer hidden, time-varying actuator faults from interaction history and adapt more effectively than feed-forward RL or explicit online system identification?

## Questions requiring evidence

- Which existing benchmarks already test abrupt within-episode dynamics changes?
- Under what observability assumptions is actuator scale identifiable?
- What history length is sufficient, and when does stale memory slow recovery?
- Which evaluation metrics distinguish adaptation from robust but non-adaptive behavior?
- What is the smallest defensible environment set under the CPU budget?
