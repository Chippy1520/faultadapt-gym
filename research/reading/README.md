# Reading Workflow

1. Research agents add candidates to `queue.csv` with primary-source links.
2. The main session removes duplicates and flags source quality.
3. Chathuka selects the anchor subset and reads those papers.
4. Create one note from `paper-note-template.md` per anchor paper.
5. Add only verified evidence to the literature matrix.
6. Record any resulting project decision separately in the decision log.

Suggested filename: `YYYY-first-author-short-title.md`.
